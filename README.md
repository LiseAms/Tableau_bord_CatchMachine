# Tableau_bord_CatchMachine
Ce repostitory github contient les codes de l'app shiny ainsi que les documents necessaires pour la faire tourner. Dernière update de l'app le 06/08/2026. 

L'export CatchMachine doit être brut pour que ça fonctionne = directement uploadé dans le Tableau de bord après le téléchargement sur CatchMachine. Le pré-traitement n'est pas nécessaire, il est inclu dans le tableau de bord. 

Dans ce Git il y a : 
- scripts : le script de l'application Rshiny, les 2 scripts dépendants pour qu'elle fonctionne (un d'appel des libraries et chargement des données, un de traitement initial des données) 
- les tableaux de données essentiels pour faire fonctionner l'application
- les fichiers shapefile pour la cartographie
